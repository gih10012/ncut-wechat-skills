# 本人消息与业务 HTTP 的范围

业务 HTTP 会话与个人客户端消息不是同一身份能力。公开文章也不代表个人订阅流。

学校业务与公众号页面的 HTTP 调用已验证。Linux 微信通过只读本机数据库取得会话及已同步的近期消息，直接使用 native 命令；ClawBot通过第三方SDK的HTTP接口读取本人发给机器人的消息，使用 bot updates。两者来源不同；微信原生发送和企微消息仍无成功证据。窗口只用于必要登录和接口发现，不作为业务读取/发送的正常回退。

2026-09-15 伴随端实验停止。普通 skill 调用不启动旧后台、不挂加密卷、不启动 Android 容器、不改本人手机/Linux 登录。

各能力分别记录验证状态和覆盖范围。读取可用不代表发送、企微或云端完整历史可用；平台状态用 partially_verified，具体判断以能力分片为准。
