# 本人消息与业务 HTTP 的范围

业务 HTTP 会话与个人客户端消息不是同一身份能力。公开文章也不代表个人订阅流。

当前已有学校业务与公众号页面的 HTTP 验证；原生微信/企微消息没有实际 API 成功证据。2026-09-14 旧 wechatcopilot 后台不可用，当前官方 Linux 微信一屏截图曾可读；后者只保留为显式人工入口，不是正常回退。

2026-09-15 伴随端实验停止。普通 skill 调用不启动旧后台、不挂加密卷、不启动 Android 容器、不改本人手机/Linux 登录。

新增消息能力先打通“指定会话近期消息”的最小请求链，记录身份和覆盖范围。API 未验证之前保持 not_connected，不用客户端截图或文档完成来代替生产验收。
