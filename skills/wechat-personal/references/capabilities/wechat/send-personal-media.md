# 个人身份媒体发送缺项

文字的任意会话 ID 支持和媒体格式支持分开记录。个人身份图片、文件、表情包、公众号卡片尚未实现或验收；不能把 ClawBot 机器人已成功的文件/图片或一条链接算作个人媒体完成。filehelper/ClawBot 的测试与媒体发送已有长期授权，其他对象按主 SKILL 的当前或适用的事先直接/间接授权执行。

正常 UI 图片观察实际得到一个目标匹配的请求类，公共请求字段值为 1、数据库消息类型为 3，两字段分别记录。先前静态图片工厂候选不是此次观察到的类，不能直接用于主动调用；真实类的工厂、路径/上传及引用生命周期尚未确定完整契约。图像探针 `scripts/native_highlevel_probe.py observe --kind image --seconds 60` 仅过滤 filehelper 图片生命周期，不发送、不读取正文或修改负载。合成 GDB 字段区分、对象/本地ID关联、时限、SIGPIPE 处理及脱离通过。两轮真实观察均安全清理，四点各命中一次但过滤差异导致没有关联事件；本人截图显示正常 UI 图片，不能当作自动发送验收。修正后的过滤未在真实客户端再次观察；本轮入口发现已到主 SKILL 的 15 分钟实际工作限时，证据和缺项已私存。

接续基于已观察类继续核对请求工厂、上传及引用生命周期；确需新运行时证据再做有界观察，不让本人重跑旧的错误过滤。之后验证请求构造与回调所有权，最后用唯一请求 ID 通过普通 CLI 真实发送并分别检查本地历史与接收端。文件与原生表情包各自验收，不重试旧同步协程调用。私有固定进程身份的一行启动脚本与证据在本机 state，正常业务不能依赖其旧 PID 或旧对话；缺项发现遵守主 SKILL 的限时规则。
