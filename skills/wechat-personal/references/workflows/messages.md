# 本人消息接入与缺项

个人微信日常读取直接用 `native conversations` 定位，再用 `native messages` 查询本机同步历史；命中既有能力不重新探索或捕获密钥，见[本机消息](native-linux.md)。朋友圈动态及指定人的完整缓存读取见[朋友圈](moments.md)，缓存末尾不代表云端全部历史。

个人身份发送优先使用已安装的独立 CLI 与辅助服务，见[独立 CLI 接续](native-cli.md)及[通用发送契约](../capabilities/wechat/send-message.md)。2026-09-30 至 2026-10-01 已分别验收普通 CLI 文字、本地入库与窗口显示、PNG/JPEG、中文文件名 TXT/ZIP、文章/小程序卡片转发与自定义 XML、文件传输助手动画 GIF；具体收件人、格式和证据以各契约及[验收记录](../verification.md)为准，不用一个格式的成功覆盖其他格式。

CLI 读写接受任意精确会话 ID，不设置授权白名单。个人身份向文件传输助手和 ClawBot 已有长期授权；其他会话依据当前任务或适用的事先直接/间接授权，已有范围不重复询问。技术验收与发送授权分别记录。ClawBot 机器人身份经 iLink 独立收发，见[ClawBot](clawbot.md)，不能替代个人身份验收；本人确认其手机端不支持自定义表情，只支持 emoji。

发送保持唯一 request-id。提交结果未知时先读原请求状态及实际接收证据，不换 ID 重试；返回任务号或零错误回调不单独证明投递。CLI 无法完成时使用 `niri-computer-use` 操作现有窗口，沿用发送授权，并先排除前次提交已成功，避免重复发送。窗口操作结果不证明原生 CLI 能力。

企业微信按本人已批准的免费独立 Wine/CLI 计划接入，见[企微 CLI](wecom-cli.md)。普通成员无企业会话存档权限，不把机器人通道、付费 WorkPro 或历史旧版 Windows hook 当作本人消息后端。鸿蒙手机通知和 Android 容器继续暂缓。

日常单项缺项探索累计最多15分钟，切换路线不重置，等待本人认证不计入；当前获授权的个人微信媒体及企微 CLI 开发例外以 SKILL.md 为准。已验证能力直接调用，缺项或异常才局部探索；不重复枚举已排除的旧版候选。历史调查保存在[OneBot记录](onebot.md)和[原生发送研究](native-send-port.md)，其旧限制不覆盖当前验收与授权。
