# 本人消息接入与缺项

Linux 微信本地读取已接通：正常需求直接用 `native conversations` 定位和 `native messages` 查询，见 [本机消息](native-linux.md)。身份、会话定位、正文解码和读回已可复用，不重新探索或捕获密钥。

剩余缺项是微信发送和企微消息。新上下文核对实际客户端、可调用工具或当前接口源码；旧后台失效只排除该条路径。接入任务无需用户先提供业务网页链接。不要为补发送重建已可用的读取链，不导出全量聊天内容，不占用桌面，不自动重建旧容器。

收消息：从真实会话列表取得会话 ID，再读取有上限的近期消息，核对实际来源和时间。发送：根据用户指定收件人和内容解析同一会话 ID，发送前核对目标，发送后凭服务返回 ID 或回读确认；超时先回查，不重复发送。没有获准的测试收件人时可完成参数准备与本地协议验证，但不能宣称已验收真实发送。

认证、会话定位、读取、发送各自有可复用接口才拆成子能力；共同的本机会话取得方式只写一个 workflow。独立设备登录只在证明能保留用户现有设备会话后采用；若需要本人扫码，先完成可交接的最小登录入口，再请本人操作。
