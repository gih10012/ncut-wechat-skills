# 本人消息 API 缺项

当前没有经本人微信/企微会话验证的消息读取、会话搜索或发送 API。旧 wechatcopilot CLI 有源码契约，但其后台不可用；历史截图只能证明当时当前一屏可见，不能算消息 API。

新上下文先核对已有客户端的当前状态、可调用工具或已有接口源码；历史后台失效只排除该条路径。接入任务无需用户先提供业务网页链接，也不因旧记录是 not_connected 就停止。调查不导出全量聊天内容，不占用现有桌面，不自动重建旧容器。

已有 Linux 微信且希望后台读取时，按 [本机密钥准备](native-linux.md) 检查一次性读取条件。该脚本已有离线 HMAC/权限/边界测试，尚需本人系统授权后实测，不能将“脚本存在”当作消息读取成功。

之后接入只以一个指定会话的近期消息为首条验收：记录真实身份来源、会话 ID 取得请求、消息读取请求、时间/分页/覆盖范围。实际请求成功后才添加命令与 runtime_verified 状态。不要先搭通用登录平台、小程序平台或历史索引。

收消息：从真实会话列表取得会话 ID，再读取有上限的近期消息，核对实际来源和时间。发送：根据用户指定收件人和内容解析同一会话 ID，发送前核对目标，发送后凭服务返回 ID 或回读确认；超时先回查，不重复发送。没有获准的测试收件人时可完成参数准备与本地协议验证，但不能宣称已验收真实发送。

认证、会话定位、读取、发送各自有可复用接口才拆成子能力；共同的本机会话取得方式只写一个 workflow。独立设备登录只在证明能保留用户现有设备会话后采用；若需要本人扫码，先完成可交接的最小登录入口，再请本人操作。
