# 本人消息 API 缺项

当前没有经本人微信/企微会话验证的消息读取、会话搜索或发送 API。旧 wechatcopilot CLI 有源码契约，但其后台不可用；历史截图只能证明当时当前一屏可见，不能算消息 API。

普通消息查询直接说明此缺项，不重复探测旧后台或尝试 UI/容器回退。用户提供的真实业务链接可以交给已验证的文章/学校/其他业务能力读取。

之后接入只以一个指定会话的近期消息为首条验收：记录真实身份来源、会话 ID 取得请求、消息读取请求、时间/分页/覆盖范围。实际请求成功后才添加命令与 runtime_verified 状态。不要先搭通用登录平台、小程序平台或历史索引。
