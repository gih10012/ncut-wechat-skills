# 当前微信窗口 → 有限内容读取

适用于已打开的本人微信会话、服务通知和客户端页面。不要读取整套旧 CLI 手册。

1. 直接运行 `python3 "$WX" desktop capture --show`，正常时不另跑 status。多个微信窗口时，用 `desktop status` 取得真实窗口 ID，再传 `--window ID`。
2. 用 `view_image` 打开返回的 `image` 路径。先识别登录状态、当前会话标题，再按用户要求读取可见范围。扫码/登录页需要本人完成；内容不符目标时不能当作目标群结果。
3. 当前只验证了窗口唤出与读取，没有可靠的选群契约。需要其他群时，请用户打开该群；不能把未经验证的快捷键后输入文字当作安全搜索。2026-09-14 的 Ctrl+F 未显示可确认的搜索状态，不能继续盲输。
4. 返回结果标明“微信当前可见内容”，保留可见日期；屏幕未显示的年份/时间不猜。只有看见小程序通知卡片，不能宣称已读取小程序内部业务。
5. 私有图片保存在 `~/.local/state/wechat-personal/runs/`，0700 目录/0600 文件。提取完成后删除本次图片；不写入技能知识。niri 截图同时会将图片放入本机剪贴板。

`desktop status` 只证明窗口存在，返回 `login_verified:false`。`desktop show` 唤出既有托盘窗口。均不启动微信、修改辅助功能设置或接入旧 daemon。调用有超时边界；同一失败不循环重试。
